## 3. 恢复出厂后 · 完整恢复流程（本日实操验证 + 三坑修正）

```
0) 前提：调试口连 PC，adb devices 可见
1) adb tcpip 5555                        ←【坑 a】每次重启后 adbd TCP 5555 失效，adb-ec 依赖它
2) ./tools/cs11_root_fire.sh             ← 已升级为"出厂后一键"：自动 tcpip + 全量推载荷（mp.sh/rootd.sh/trig/root_cmd.sh/pppd）+ 点火 + rootd 验证
     【坑 b】trig 必须二进制魔数（首 4 字节不可打印）；纯文本会被内核
             "首 4 字节全可打印则不请求 modprobe" 检查拦下 → 整条链静默不触发
     【坑 c】root_cmd.sh 里 toolbox chmod 报 "Operation not permitted" 无害（文件已由 adb 端 chmod 755）
     【坑 d】adb.exe 是原生程序，本环境不转 MSYS 路径——脚本已内置 cygpath 转 D:/ 形式
3) 验证：/data/.android/mp_run.txt 有 "MP TRIGGERED" + CapEff 全 37 位；ps 见 rootd.sh
4) 装 APK：adb install -g -r _artifacts/cs11_apk/mobile-debug-d8611cd-20261007.apk
5) iPhone 插 USB2 → am start -n com.shihab.diplay.hudtest/com.shilapi.xcertplay.CarPlayHostActivity → 等 NCM 引导（fe80::2）
6) 调优重放：push tools/cs11_tune.sh → /data/.android/rootcmd.sh（或直接 ./tools/cs11_recover.sh）
7) 核验：ifconfig usb1 / Udp6InErrors≈0（空闲）/ 屏幕出 CarPlay
```
