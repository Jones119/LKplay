# 12 · CS11 开源资源普查（网上到底有什么）

> 日期：2026-10-06 ｜ 方法：GitHub API 全站搜索（多轮关键词）+ Gitee + 网络检索，逐项核实仓库元数据
> 结论：**CS11 专属开源代码全网仅 1 个**（我们已在用）；官方/系统/内核源码零公开；同族平台社区活跃但 SoC 代际不同、不可直套；CarPlay 侧发现重量级参考 **f-io/LIVI**（已克隆）。

## 1. CS11 专属：仅 1 个仓库

- **`cjlhll/cs11-carplay-dongle`** ★1 ｜ 61.8 MB ｜ 更新 2026-09-18 —— 唯一 CS11 专门仓库。
  - 内容：盒子固件 dump（uboot/rootfs/zImage）、盒子 APK ×2（原版 + 脱壳）、`docs/PROTOCOL.md`、新工程 `hu/`（车机端 APK `cn.carplay.hu`）+ `proxy/proxy.py`（PC 代理）。
  - 其路线：盒子 → PC 代理 → `adb reverse` → 老安卓机 = **仍依赖盒子**，与我们的"纯软件直连"不同，但协议文档/固件 dump 可对照。
  - 本地副本：`_upstream/cs11-carplay-dongle/`（含全部工件）。

## 2. 官方开源：零

- ECARX/吉利无官方 GitHub 组织（`ecarx` 账号 = 2017 年无关项目）；未发现 GPL/开源门户；CS11 内核/系统源码无任何公开发布。
- 车机固件现状：仍靠非官方 dump（我们已有的提取件）。

## 4. 能合法拿到的"开源半边"

- **AOSP 4.4.3** —— 车机框架的基座（对照工作一直在做）；
- **NXP i.MX6 Linux 3.10 BSP** —— 车机内核的母体（车机内核 = ECARX 魔改分支；可对照驱动与编译配置）；
- CarPlay 侧开源栈 ×2：
  - DiPlay / xcertplay（本项目基座）；
  - **`f-io/LIVI`** ★851 ｜ Rust ｜ GPL-3.0 ｜ 当日仍在更新 —— Linux/macOS 原生 CarPlay/Android Auto 车机（**有线 + 无线**、自建 Wi-Fi AP + 蓝牙配对、需 MFi 身份）。

## 5. LIVI = 下阶段"有线引导→Wi-Fi 媒体"的直接参考（已克隆 `_upstream/livi/`）

| 文件 | 内容 |
|---|---|
| `native/livi-helperd/crates/iap2-csm/src/messages/wifi.rs` | **0x5702 / 0x5703 消息结构定义** |

用途：施工"混合方案"时对照其**握手顺序、0x5703 字段、会话管理**，减少试错。

## 6. 结论

- 没有现成 CS11 源码可捡；ECARX 魔改层（`EthernetDataTracker` 等）只能反编译——ASC 已证明够快。
- 净收益三项：① LIVI 无线实现（下阶段直接参考）；② GInputBridge / CarExt SDK（同族 API 情报）；③ 无其它。
- 备忘（备案不动手）：CS11（i.MX6Q）若有 U-Boot/串口等硬件入口，"刷自编译内核（带 TUN）"理论上是远期可能——风险高，不作当前路线。
