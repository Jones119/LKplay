# 03 · 领克 CS11 车机兼容性评估（DiAuto vs DiPlay）

评估日期：2026-10-06 · 结论基于：两个发布版 APK 的实测元数据 + CS11 平台的公开信息

## 车机是什么

- **CS11** = 领克 01/02/03（18–21 款中高配）的安卓车机平台，与后来 820A/E03 车机不同代。
- 硬件/系统（社区实测）：NXP **i.MX6Q**（四核 Cortex-A9，32 位 arm）、**2GB RAM**、**Android 4.4.3**。
  - 来源：V2EX 帖（19 款领克 03 车主："安卓版本是 4.4.3"）；汽车之家 02 论坛帖（"车机用的是安装 4.43…4 核 A9"）。
- 领克官方已明确 CS11 **无升级计划**（汽车之家论坛）；社区安装第三方 APK 的方式是**用电脑 ADB**（B 站有现成教程："领克03CS11车机使用电脑安装第三方应用"）。

## 两个应用的安装门槛（APK 实测）

| APK | minSdk | 含 32 位原生库 | 在 Android 4.4.3 上 |
| --- | --- | --- | --- |
| `DiAuto-v0.3.11.apk` | **16**（Android 4.1） | ✅ armeabi-v7a | **可安装** |
| `DiPlay-0.2.12.apk` | **28**（Android 9） | ✅（但也无关了） | **无法安装**（系统直接拒装，INSTALL_FAILED_OLDER_SDK） |

## 结论

1. **iPhone 用户：DiPlay 不可行**。CS11 是 4.4.3，DiPlay 要求 Android 9+，且无线/仪表功能全是 BYD 专属。改走 CarPlay 盒子方案（Carlinkit 类 USB 盒子 + 车机端 Carlink/AutoKit 类应用，社区有 CS11 教程），或用车上的原厂手机互联。
2. **安卓手机用户：DiAuto 是唯一可尝试的**（两项目里）。预期管理：
   - **优先 USB 有线**（最可能成功；CS11 原厂 CarLife 走 USB，说明数据通道存在，USB host 大概率可用）。
   - **无线成功率低**：需要车机蓝牙支持被手机反向连接 + Wi-Fi Direct/热点创建能力，老车机情况未知；备选路径是手机开"Android Auto 开发者设置 → Headunit Server"、车机与手机同一网络时用扫描模式连接。
   - **BYD 专属功能全部无效**（HUD/仪表、热点恢复、5GHz 对齐、BSSID 恢复等只是不生效，不会报错）。
   - 性能上 2GB RAM + A9 很勉强；视频走 i.MX6 硬件解码（H.264 可行），v7a 没有 FFmpeg 软解兜底。
3. **更贴合"任意老安卓车机"的替代**：上游 **open-headunit**（DiAuto 的源头项目，官方支持 Android 4.1+、对旧设备优化更多、仍在活跃更新）。
   - ⚠️ DiAuto 与 open-headunit **同包名**（`com.andrerinas.headunitrevived`）但**签名不同** → 不能共存、不能互升，切换时必须先卸载。
4. **官方支持边界**：两个项目 README 均声明仅支持 BYD、其他品牌"不受支持、也不会修品牌专属问题"；DiPlay 的 issue 审计里吉利相关请求（#149 求吉利版、#160 Coolray、#165 吉利 Android 11）均为关闭/未支持状态。

## 建议的操作步骤（安卓手机）

```sh
# 1. 先确认（停车后操作）
adb connect <车机IP>:5555        # CS11 需先在电脑上通过 ADB 连车机
adb shell getprop ro.build.version.release   # 预期 4.4.3
adb shell getprop ro.product.cpu.abi         # 预期 armeabi-v7a

# 2. 安装（从已下载的发布版）
adb install -r D:\Development\DiAuto-DiPlay\_artifacts\DiAuto-v0.3.11.apk

# 3. 先试 USB 有线：车机端点 Connect → USB，手机（已装 Android Auto）用数据线连接并确认
# 4. 无线备选：手机开发者选项启动 Headunit Server，车机接入同一热点后扫描连接
```

如遇崩溃/黑屏，`adb logcat` 抓日志（DiAuto 自带诊断导出：Settings → Diagnostics）。
