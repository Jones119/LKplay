## 4. 构建与身份注入机制（已亲读 mobile/build.gradle.kts）

- `minSdk 28 / targetSdk 37 / compileSdk 37`；Compose；Java 11；applicationId `com.shihab.diplay`；版本 0.2.13 (vc32)
- **身份资产注入**：环境变量 `DIPLAY_AUTH_ASSETS_DIR` → `sourceSets.main.assets.srcDir`；内容要求 `offline-mfi/identity.pk8` + `offline-mfi/certificate.p7b`
- 守卫任务：`rejectBundledCredentials`（preBuild 拒绝意外凭据文件）、`verifyStandaloneAuthentication`、一键任务 `assembleStandaloneDebug`
- **我方复用路径**：用我们提取的身份资产目录（`_artifacts/apk_assets/`）走同一机制即可复现"可上车测试"的构建；正式自用构建再决定资产策略（本地注入，不落库）
- 附注：debug 变体带 `.hudtest` 后缀；release 关闭了优化（`optimization.enable=false`）
